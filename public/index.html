    Como usar
    Duplo clique numa caixa para entrar no nível seguinte. Arraste o ponto lateral para ligar a outra caixa. Duplo clique no fundo cria uma atividade. Arraste o fundo para deslocar o quadro. Com Espaço carregado, arraste no fundo para selecionar várias caixas e mova-as juntas; Shift+clique junta ou retira caixas. Arraste ficheiros do computador para uma caixa para os anexar.
    Enter entrar · Esc subir · Del apagar · Ctrl+A selecionar tudo · Ctrl+Z anular · roda do rato desloca, Ctrl+roda faz zoom · Espaço+arrastar seleciona várias caixas
    Diagrama vazioAdicione caixas com a paleta à esquerda ou faça duplo clique no fundo. Depois ligue-as arrastando o ponto lateral.
